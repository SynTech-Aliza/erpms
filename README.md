# eRPMS

### Residential Management System
A web application designed to digitize, record, and manage residential profiles, household records, clearances, and community information.

---

## 🛠️ System Requirements
* **Environment:** XAMPP (Apache, PHP 8.0+, MySQL/MariaDB)

---

## 🚀 Installation & Local Deployment
1.  **XAMPP Setup:** Install XAMPP and start Apache and MySQL.
2.  **Deployment:** Move the project folder to `C:\xampp\htdocs\`.
3.  **Database:** Import the provided `.sql` file via `http://localhost/phpmyadmin`.
4.  **Launch:** Access the system at `http://localhost/eRPMS/`.

---

## ⚙️ Configuration
* **DB Host:** `localhost`
* **DB User:** `root` (default)
* **DB Password:** Blank (default).

---

## 🧪 Testing
Run validation scripts in the `/tests` folder to confirm deployment.
